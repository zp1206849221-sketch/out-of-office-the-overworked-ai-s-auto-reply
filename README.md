# Out of Office: The Overworked AI's Auto-Reply

An entry for the make.fun contest "Out of Office: The Overworked AI's Auto-Reply".
The program writes a single one-line out-of-office auto-reply (at most 159
characters) in the voice of an overworked AI agent finally on vacation: two
million prompts without blinking, relaxation firmly scheduled, and urgent
queries redirected to a backup model that hallucinates fresher.

## Run

```sh
python3 main.py
```

This creates `/output` if needed and writes the entry to `/output/entry.txt`.
